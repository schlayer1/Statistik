ℹ️ Wie richte ich Firebase kostenlos ein?

1. Gehe auf console.firebase.google.com und erstelle ein kostenloses Projekt.

2. Klicke im Menü auf Firestore Database → Datenbank erstellen (im Testmodus oder mit den bereitgestellten Regeln).

3. Klicke auf das Zahnrad ⚙️ (Projekteinstellungen) → App hinzufügen (Web </>) und kopiere das firebaseConfig-Objekt.

4. Füge den Code hier in das Textfeld ein und klicke auf Verbinden & Speichern. Fertig!
